# ZorMarket downloads

Windows downloads of **ZorMarket**, an online co-op supermarket party game in early beta, made by
[Mirsaid Abbasov](https://mirsaidabbasov.com).

**Official site: https://zormarket.mirsaidabbasov.com**

This repository only hosts the installer and the portable zip of each beta build (see Releases). It holds no source code.
